This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project status

This repository is in its **initial scaffolding stage** — there is no source code committed
yet (no commits on `master`). It is intended to become a **Python client/integration for the
Globo Ads "Resultados" (Results) API**.

Two reference artifacts exist at the root:

- `.env` — holds the API credential. Currently a single `token=...` entry. **Not committed**;
  keep it untracked and load it at runtime (e.g. `python-dotenv` / `os.environ`).
- `Gads Results API Documentation pt-BR.html` — the **canonical API reference** for the Globo
  Ads Results API, generated by [apiDoc](https://apidocjs.com/), in Brazilian Portuguese. It is
  the source of truth for endpoints, request/response shapes, and auth. Note: it is a standalone
  apiDoc page whose endpoint data normally loads from sibling `api_data.js` / `api_project.js`
  files which are **not present**, so it renders "Loading..." when opened directly. To read the
  actual endpoint definitions, obtain those data files or view the doc from its original host.

When adding code, consult this HTML doc for the exact API contract rather than guessing.

## Conventions for this project

- **Language:** Python 3.10+ (`python3` resolves via pyenv on this machine).
- **Secrets:** Read the API token from `.env` / environment — never hardcode it and never commit
  `.env`. Add a `.gitignore` covering `.env`, `__pycache__/`, `.venv/`, and `*.pyc` early.
- **API language:** The upstream API and its docs are in Portuguese; field names in responses
  will likely be Portuguese. Preserve them as-is when mapping to models.
